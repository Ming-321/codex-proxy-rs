# v3.18.2

## 问题修复

- 修复热点诊断在分组超过 100 项时请求占比偏高的问题，分母使用筛选范围内全部匹配请求；重试率按发生重试的请求数计算，同一请求多次重试只计一次
- 系统更新弹窗点击后立即打开，加载期间显示骨架屏；修复关闭时发布说明提前消失、面板高度跳变的问题

## 计费与管理界面

- 补充 GPT-6.1 Sol 内置计费规则，覆盖长上下文、服务档位、缓存与搜索费用
- 热点诊断的账号维度和使用记录增加当前套餐列，调整列宽、对齐及套餐徽标对比度，减少诊断卡片空白
- 精简额度预测弹窗，移除剩余额度行，周期标签统一为“周额度”和“月额度”；平台与套餐放到邮箱下方，说明图标移到更新时间后
- API 密钥前缀超出列宽时直接裁切，保留脱敏显示与复制按钮

## 升级说明

- 额度预测接口不再返回 `remainingTokens`、`remainingUsd` 及对应的 `*Display` 字段；直接使用该接口的客户端需同步调整，预计总量的计算规则保持不变
- 套餐列展示账号当前套餐，不是请求发生时的套餐快照；月额度缺少对应上游窗口时仍按 30 天折算，并保留折算提示
- v3.18.0 的更新清单解析限制仍适用，需使用完整平台发行包或容器镜像升级；二进制部署须成套替换程序、Web 资源和 `plugins/official` 目录
