# v3.17.0

## 新增功能

- 账号列表新增并发容量标记，在额度进度条上方显示当前执行占用与有效上限，支持不限、未知和满载状态；数据随列表查询刷新，不包含排队请求
- 插件新增 Client Key 日／周预算查询、限额调整与用量重置，以及账号额度观测刷新能力；可读取 Key 的启用状态和显式分组绑定，无需读取密钥或账号凭据
- Responses WebSocket 支持中断当前响应，中断绑定原账号与原上游连接；上游确认中断后保留有效的续接能力

## 问题修复

- 开启账号排队时，OpenAI 会话绑定的账号因本地并发、请求间隔或已有等待者暂忙，会优先等待原账号；队列满或等待超时不再因此迁移绑定，并区分本地容量不足与没有可用账号
- 隔离 OpenAI 账号专属的路由、身份及 Guardian 响应引用，避免切换账号时沿用原账号上下文
- 扩大流式响应前导事件的短暂缓冲，为尚未向客户端交付时收到的明确拒绝保留换号恢复机会；实际输出到达后立即放行，并补充缓冲释放原因的诊断记录
- OpenAI 额度刷新失败时提供更明确的错误提示，避免额度查询失败误改凭据状态，并保留并发凭据刷新产生的有效结果

## 体验优化

- 系统更新弹窗固定进度与日志区域，区分历史失败和当前任务错误，避免旧失败记录让当前安装状态显示异常
- 概览静默刷新保留已有内容，客户端身份预设加载时保留表单布局，并统一 Key 用量页面的工具栏与刷新反馈

## 升级说明

- 本版未新增或修改数据库迁移，沿用 v3.16.0 的数据库结构；升级前请备份数据库并保留现有配置
- 使用新增插件接口需升级宿主并授权对应能力；预算管理权限覆盖全部 Client Key，额度观测刷新不会重置上游额度，宿主不会自动联动账号额度与 Key 预算
- 部署文档补充 Redis ACL 用户配置方式，以及 Compose 中 `CPR_REDIS_URL` 对配置文件的覆盖规则
