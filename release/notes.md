# v3.15.0

## 新增功能

- 扩展 OpenAI 客户端身份配置：支持 CLI 的 Core、TUI、Exec 入口和完整自定义用户代理，自动识别官方身份对应的请求头；官方预设继续通过每日检查跟随官方版本，可用于全局设置和密钥独立配置
- 插件支持发布模型别名，模型列表与请求路由共用目录，并沿用目标模型的能力和访问范围
- 新增插件只读 `data` 访问域，可查询账号基础信息和已有额度观测，展示类插件无需申请凭据访问权限
- 插件可在宿主允许的范围内参与重试决策；中间件 v2 支持声明由插件承担的功能转换，宿主继续校验实际请求的路由需求

## 问题修复

- 修复过期代理测试结果返回冲突后，事务锁尚未释放可能导致紧接着的代理编辑也报冲突的问题
- 修复客户端身份切换后恢复原配置，系统设置仍被误判为未保存的问题
- 保留中间件未修改的请求正文、请求头与响应流内容，避免仅解析或观察数据改变透传结果

## 体验优化

- 客户端身份沿用紧凑的预设与版本策略布局，选择自定义版本时自动带入当前用户代理；精简重复说明、调整加载状态，并统一相关工具栏按钮样式
- 插件配置的资源选择复用多选控件，简化模型、账号等资源的选择与回显

## 开发与协作

- 增加组件库与插件示例的源码联调入口，支持本地 UI 热更新、源码构建和 SDK 联调检查，正式构建继续使用锁定依赖
- 仓库技能统一使用 `cpr-` 前缀，明确开发与 PR 流程、后端自审、页面截图及 AI 模型披露要求

## 升级说明

- 从 v3.14.1 升级未新增或修改数据库迁移，继续使用现有配置与数据
- 使用新增插件能力时需更新公开 SDK，并部署支持对应能力版本的宿主；现有中间件 v1 仍受支持
