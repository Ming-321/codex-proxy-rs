# v3.18.0

## 新增功能

- 插件中间件覆盖 HTTP、WebSocket 消息、公开服务、模型请求与单次上游尝试，支持按阶段配置启停、顺序和失败处理
- 新增 OpenAI / xAI 受管上游适配器，插件可指定业务上游并解析结果，同时复用宿主的账号选择、重试和用量结算
- 统一插件事件观察接口，分别订阅请求完成与用量、上游 WebSocket 事件；账号只读事实增加名称和邮箱

## 问题修复

- HTTP Responses 请求省略 `stream` 时默认返回 JSON，修复调用方按普通 JSON 解析时收到 SSE 的问题；显式流式请求和 WebSocket 默认行为保持不变
- OpenAI 上游连接池、TCP keepalive 和 HTTP/2 keepalive 设置与官方 Codex 默认行为对齐
- 二进制部署自重启保留启动时解析的安装路径，修复更新替换可执行文件后重启路径失效的问题，并补充自重启配置示例
- 调整账号列表的并发容量对齐和每日用量显示，改善额度摘要的布局

## 插件与升级说明

- 插件安装采用完整信任模型，不再以权限清单表达隔离；插件与网关使用相同系统身份，可访问数据、凭据、配置与网络，只安装可信来源
- 当前插件合同为 `manifestVersion: 2`、进程协议 `2`、中间件能力 `3`。旧合同插件需使用匹配的 SDK 与 CLI 重新构建打包，不能仅修改版本字段；Workbench 可安装 [v0.2.0](https://github.com/zyycn/codex-proxy-plugins/releases/tag/v0.2.0)
- v3.17.0 内置更新器不支持本版的插件兼容声明，需使用完整平台发行包或更新容器镜像。二进制部署请成套替换程序、Web 资源和 `plugins/official` 目录；升级前停用不兼容插件，升级后安装兼容版本并检查配置
- 新增数据库迁移 `0020_plugin_trust.sql`，清理插件制品元数据中的旧权限字段，保留包体、摘要、接受记录与实例配置；已发布迁移保持不变。升级前请备份数据库并保留现有配置
- 依赖 HTTP Responses 默认 SSE 的调用方需显式传入 `stream: true`
