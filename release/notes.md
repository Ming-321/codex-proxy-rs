# v3.18.1

## 问题修复

- 在线更新不再因插件不兼容而阻止安装，点击重启时检查已安装目标版本，列出不兼容插件的名称与原因，确认后停用这些插件并重启
- 确认绑定目标发行和插件配置，检查后发生变更时要求重新确认；取消不修改插件状态，批量停用保留配置、密钥与私有数据
- 插件管理使用黄色警告三角展示不兼容原因，禁止启动不兼容插件，安装兼容版本后可重新启用
- 兼容更新文件已安装、旧进程尚未重启时的管理端操作，保留旧版本的重启入口

## 升级说明

- 从 v3.17.0 升级：插件已卸载或全部停用时，可直接在线更新到本版；仍启用旧合同插件时，需先停用一次，旧进程不能提前使用新版确认流程
- 本版发行清单保留 v3.17.0 可解析的传输格式，实际支持范围仍为清单 2、进程协议 2、中间件能力 3，不宣称兼容旧插件
- v3.18.0 的清单解析规则与 v3.17.0 互斥，无法读取此过渡格式；已运行 v3.18.0 的实例需用完整平台发行包或容器镜像升级一次。二进制部署须成套替换程序、Web 资源和 `plugins/official` 目录
- 进入本版后的后续在线更新使用重启前检查与确认流程，Workbench 可安装 [v0.2.0](https://github.com/zyycn/codex-proxy-plugins/releases/tag/v0.2.0)
