# 自用版 3.13.1+car.4

拼车管理并入分组管理。创建与后续调整在同一页完成：绑定账号、安排车位、纳入或新增 Key、选择客户端身份、设置共享限制，预览后一次保存。失败保留草稿，重复提交不会重复创建 Key。

- 额度、并发和 RPM 统一属于车位，增加 Key 不增加配额。已有成员中最严格的有限 RPM 迁为共享 RPM；本次自用部署两个车位各为20 RPM。
- 支持几人车精确均分与一位小数的自定义份额。空车位、停用车位仍占份额，未分配部分保留。
- 旧的单车位保存接口也按整车重算均分；拒绝因金额精度截断而意外变成不限的分配。
- 每辆车可选择手动、跟随账号周期或自动估算。通用默认手动，自用安装通过设置明确默认自动；首次启用自动须确认初始总额度。
- 自动调额沿用6小时等保护，不清空费用；关闭自动转为跟随周期时保留金额。切回手动窗口须能核对账本且无在途请求。

追加0021迁移，保留已发布的0001—0020。已有车的总份额、成员份额、身份、费用、确认周期、预测参数与最近发布时间保持。升级应先排空并备份；回退旧程序必须配合匹配的数据库结构，恢复旧备份仅适用于尚未放流的升级。放流后不得用旧备份覆盖新增账务。

本版本只用于个人 fork 的部署，不更新上游两个 PR。
